# Recipes

This directory is the canonical GitHub home for household recipes produced or curated by the Inventory Recipe Cartridge.

## Purpose

Recipes should not live only inside chat transcripts, receipts, or cartridge examples. Final usable recipes belong here so they can be found, revised, audited, printed, and reused.

## Directory structure

- `recipes/index.md` — human-readable recipe index.
- `recipes/family/` — shared-family recipes that are intended to be allergy-aware by default.
- `recipes/adult-only/` — recipes that include dairy, egg, wheat, or other ingredients not safe for all children.
- `recipes/receipts/` — recipe-generation receipts and provenance notes.

## Safety conventions

Each recipe should declare:

- allergy status
- label checks
- Robert fit
- wife/breastfeeding fit
- toddler fit
- sodium and added-sugar risk
- source/provenance

Default shared-family recipes should be dairy-free, wheat-free/GF, egg-free, peanut-free, and tree-nut-free unless specifically labeled otherwise.
